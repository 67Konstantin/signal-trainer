# Сигнал — семафор и азбука Морзе

[Открыть тренажёр](https://67konstantin.github.io/signal-trainer/)

Самостоятельный HTML-файл для русского и латинского алфавитов. В каждом уроке доступны разучивание по карточкам, практика и проверка без подсказок. Проверка смешивает приём и передачу; после раунда с ошибками повторяется весь выбранный урок до раунда без ошибок. Неверный ответ показывается рядом с правильным.

Для каждого алфавита есть банк из 500 слов. Подборки по 5, 10 или 20 слов выдаются без повторов до исчерпания банка; разучивание и проверка могут использовать одну и ту же подборку. После букв идут слова: семафор показывает их флажками по очереди с управлением скоростью, паузой и повтором; в Морзе слова читаются как группы кодов и передаются с пробелами между буквами. Для флажков доступен вид спереди и со спины. Прогресс хранится локально в браузере. Сервер и внешние JavaScript-библиотеки не требуются.

Источники таблиц указаны внизу страницы.
