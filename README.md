# Сигнал — тренажёр семафора и азбуки Морзе

Самостоятельный HTML-тренажёр для русского и латинского алфавитов. Откройте `index.html` локально или используйте [опубликованную версию](https://67konstantin.github.io/signal-trainer/).

Включает чтение знаков, передачу букв, зеркальный вид для постановки флажков, короткие уроки, повторение ошибок и локальное сохранение прогресса. Сервер и внешние JavaScript-библиотеки не нужны.

Источники таблиц указаны внизу страницы.
